# React Password Generator

This is a simple password generator application built with React.js. It allows users to generate secure passwords based on their preferences.

## Features

- Generate random passwords
- Customize password length
- Include/exclude numbers, symbols, and uppercase/lowercase letters

### Prerequisites

- Node.js (version 14 or higher)
- npm (Node package manager)

### Usage

To start the application, run the following command:

```bash
npm start
```

This will start the development server and open the application in your default web browser.

### Built With

- React.js
- CSS
